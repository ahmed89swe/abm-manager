# ABM Manager

نظام أندرويد لإدارة الأموال والفواتير والصناديق بين الشركة والمدير والمندوبين والعملاء (أطباء، صيدليات، مذاخر).

## الميزات الرئيسية
- **إدارة الإصدارات والتحديثات**: دعم التحديث الإجباري والاختياري من لوحة تحكم المدير.
- **الإشعارات السحابية**: إشعارات فورية عبر السحابة وFCM عند أي عملية مالية أو إدارية.
- **الصندوق العام والصناديق الشهرية**: صندوق سري خاص بالمدير يتكون من الصناديق الشهرية (تُقبل فيها الأرصدة السالبة) + صناديق افتراضية فرعية للمندوبين.
- **الفواتير والثوابت**: إدخال حصري للثوابت (محافظات، أطباء، صيدليات، مذاخر، مواد) من قِبل المدير، وفرض توقيت السيرفر على المندوبين، مع دعم السعر الاختياري وإرفاق صور الوصولات.
- **التقارير والمصاريف وسجل العمليات**: تقارير تفصيلية للمدير مع تصدير PDF ورسوم بيانية، تبويب مصاريف شخصية، وسجل عمليات شامل.
- **واجهة ثنائية اللغة والمظهر**: دعم كامل للعربية (RTL) والإنجليزية (LTR) مع الوضع الفاتح والداكن.

## إعداد Firebase السريع (`abm-manager-sys`)
تم إنشاء المشروع السحابي `abm-manager-sys` وربطه تلقائياً عبر `google-services.json` و `lib/firebase_options.dart` ونشر قواعد `firestore.rules`.
للتشغيل الكامل على السحابة من [Firebase Console](https://console.firebase.google.com/project/abm-manager-sys/overview):
1. تفعيل **Authentication -> Email/Password**.
2. إنشاء قاعدة بيانات **Cloud Firestore** (اختيار الموقع مثل `eur3` أو `me-central1`) ثم نشر الفهارس: `firebase deploy --only firestore:indexes`.
3. تفعيل **Firebase Storage** ثم نشر القواعد: `firebase deploy --only storage`.
